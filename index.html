User guide

How Hifz works, end to end

Hifz helps you memorise the Qur'an by listening in a structured, repeating pattern — the "stacked" method — and by making plain listening tracks. Everything works offline once loaded, and audio keeps playing with the screen locked.

The stacked method

Rather than replaying a whole passage over and over, stacking builds it up ayah by ayah, replaying what came before each new one so the joins stick. For ayat 1–5 with "each ayah ×3" and "range ×5", you hear:

Ayah 1 ×3 → (1) then 2 ×3 → (1,2) then 3 ×3 → (1,2,3) then 4 ×3 → (1,2,3,4) then 5 ×3 → then the whole 1→5 five times.

The bracketed part is the stack — earlier ayat played once before each new ayah. You control how deep it goes.

Memorize tab

Choosing a passage

  • Type in the surah box to filter — English name, Arabic (with or without harakat), the meaning, or the number. E.g. yaseen, يس, 36, or cave.
  • Set the ayah range with the two boxes.
  • Show text loads the verses without downloading audio — check the range is right first.

Repetition

  • Each ayah repeats — how many times a single ayah plays before moving on.
  • Whole range repeats — how many times the full passage replays at the end.
  • Stack depth — how many earlier ayat replay before each new one. "All previous" is the fullest.

Playing

Tap Start. Hifz downloads the ayat (kept for next time), joins them into one continuous track, and plays. The verses show on screen and the current one is highlighted. A back arrow returns you to the setup.

If a track is long and the browser blocks auto-start, you'll see Ready — tap Play. That's normal; one tap begins it.

Stitch tab

Builds a plain listening track — each ayah once, in order, no repeats. Add blocks (surah + range); blocks can cross surahs, and Bismillah opens each new surah. Good for revision or just listening.

Saving to your phone's player

After a track is built, two buttons appear:

  • For listening — a plain MP3.
  • For Musicolet — an MP3 with the verses embedded inside it, plus a matching .lrc file, delivered as one zip.

Setting up Musicolet

1. Export "For Musicolet" → a zip lands in Downloads.
2. Extract the zip into a folder.
3. Open that folder in Musicolet and play.
4. Verses appear on screen and lock screen as each ayah is recited.

The verses ride inside the MP3, so even without the .lrc a player that reads embedded lyrics will show them. The .lrc is there as a reliable fallback.

Copying verses

On the reading screen, each ayah has a small copy button, and Copy all verses copies the whole passage (with verse numbers) as Arabic text.

Settings worth knowing

  • Reciter — four to choose from.
  • Drill pause — silence after each ayah: none, a fixed length, or as long as the ayah (to recite it back).
  • Veil ayat ahead — blurs upcoming ayat so your eye can't run ahead.
  • Arabic / Interface size — scale the text to taste.
  • Verses in exported MP3 — the embedded-lyrics feature above.

Backups & storage

Downloaded audio is kept on your device so it never re-downloads. Delete all downloaded recitation frees that space. Export backup (Saved tab) saves your ranges, recipes and settings to a file that survives even a full reset — keep one.

If something goes wrong

The Activity log on the playing screen shows each step and any error with a code (e.g. NET_AUDIO_404). Tap Copy there to grab the whole log if you need help.
